# Карта тривог v2 (ESP32-C3)

## Як залити
1. Відкрий цю папку в VS Code з розширенням PlatformIO.
2. PlatformIO → esp32c3 → General → **Upload** (прошивка).
3. Веб-інтерфейс, один із двох способів:
   - PlatformIO → esp32c3 → Platform → **Upload Filesystem Image**, або
   - нічого не заливати: відкрий сторінку пристрою в браузері, вона запропонує вибрати файл `data/index.html` і завантажить його сама.
4. Монітор порту: 115200.

Якщо на платі стоїть міст USB-UART (CH340, CP2102), обирай середовище `esp32c3-uart`.

## Оновлення без кабелю
Вкладка **Система**, два способи.

**З файлу:**
- «Оновити прошивку»: файл `.pio/build/esp32c3/firmware.bin`;
- «Завантажити»: новий `index.html`.

**З GitHub:** вкажи репозиторій у форматі `користувач/репозиторій`, натисни «Зберегти», далі «Перевірити оновлення» і «Встановити». Якщо ввімкнути автоматичне встановлення, карта перевіряє реліз раз на добу.

## Як викласти нову версію на GitHub
Репозиторій має бути публічним. В останньому релізі мають лежати файли: `version.json` (вигляду `{"version":"2.3.1"}`), `firmware-esp32c3.bin` та `index.html`.

Автоматично (файл `.github/workflows/release.yml` уже є в проєкті):
```
git tag v2.3.1
git push origin v2.3.1
```
GitHub сам збере прошивку з номером версії з тега і опублікує реліз.

Вручну: зміни `FW_VERSION` у `include/config.h`, збери проєкт, створи реліз на GitHub і прикріпи до нього ці три файли (прошивку з `.pio/build/esp32c3/firmware.bin` перейменуй на `firmware-esp32c3.bin`).

Номер версії в релізі має бути більшим за встановлений, інакше карта вважатиме, що оновлюватись не треба.

**Токен alerts.in.ua не пиши в `config.h`**, якщо проєкт лежить у публічному репозиторії. Введи його у вкладці «Налаштування»: він зберігається лише в пам'яті пристрою.

## Перший запуск
- Wi-Fi ще не налаштований, тому карта піднімає точку доступу `AlertMap-XXXX` (пароль `alertmap`) і дихає бірюзовим.
- Підключись до неї з телефона, сторінка налаштувань відкриється сама. Якщо ні, відкрий http://192.168.4.1
- Вкладка **Wi-Fi**: обери мережу, введи пароль, збережи.
- Вкладка **Налаштування**: введи токен alerts.in.ua.
- Далі сторінка доступна за адресою http://alertmap.local (або за IP з роутера).

## Прив'язка світлодіодів
Кожен світлодіод можна прив'язати до цілої області або до окремого району (126 районів, список узято з alerts.in.ua).

Вкладка **Прив'язка світлодіодів** → «Почати». Карта по черзі засвічує світлодіоди білим. Торкнись області, де він горить, і обери «Вся область» або потрібний район. Наприкінці натисни «Зберегти». До однієї області чи району можна прив'язати кілька світлодіодів.

Як рахується стан:
- світлодіод області: тривога, якщо вона на всю область; «частково», якщо лише в окремих районах чи громадах;
- світлодіод району: стан самого району, а якщо тривогу оголошено на всю область, то стан області.

## Що означають кольори
| Стан | Вигляд |
|---|---|
| Спокійно | прапорна схема або один колір, горить рівно і тьмяно |
| Тривога / червоний рівень | червона пульсація |
| Жовтий рівень (API v2) | помаранчева пульсація |
| Частково | бурштинова пульсація |
| Немає даних понад 3 хв або помилка API | фіолетове повільне дихання |
| Підключення до Wi-Fi / точка доступу | синє / бірюзове дихання |

## Як розподілено роботу
У ESP32-C3 одне ядро. Запити до API, анімація світлодіодів і веб-сервер працюють окремими задачами, світлодіоди мають вищий пріоритет, тому анімація не зупиняється під час запиту.

Код однаковий із версією для ESP32-S3, відрізняються лише `platformio.ini` і назва файлу прошивки в релізі.

## Підключення
- DIN стрічки → GPIO 4 (змінюється в налаштуваннях). Підходять 0, 1, 3–7, 10.
- Між GPIO і DIN став резистор 330 Ом, на живлення стрічки конденсатор 470–1000 мкФ.
- Якщо світлодіоди глючать, сигналу 3,3 В замало для 5-вольтової стрічки. Тоді додай перетворювач рівня 74AHCT1G125.

## Ресурс флеш-пам'яті
Налаштування пишуться в NVS лише тоді, коли натискаєш «Зберегти». Стан тривог не пишеться нікуди.
